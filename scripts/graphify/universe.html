Explore your universe

Code stars are Graphify symbols. Blue diamonds are allowlisted Obsidian project notes. Note links mean an explicit file mention, not a verified dependency. Background specks are decorative.

Navigate: drag to rotate, Shift-drag to pan, scroll or pinch to zoom. Arrow keys rotate; + and − zoom.

Find: search labels or file paths. Press Enter to select the first match, or Tab through results. Select a star to inspect and follow its connections.

Focus: use Focus in the inspector to centre a symbol. Reset view restores filters and camera. Escape clears selection and search. Orbit is optional and starts paused.

Payments matches repository file paths without AI. Notes show headings and explicit references only; originals stay in Obsidian. The live viewer updates automatically after verified publication and note-metadata changes. Exported HTML remains an offline code snapshot.
