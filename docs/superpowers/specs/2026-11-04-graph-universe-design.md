# Wolf Forge Universe

The owner requested a universe-style view of existing Graphify data and selected a rotatable, zoomable 3D galaxy over a flat constellation. The viewer is a local code-navigation surface for the owner; coding agents keep querying the unchanged graph.

Use a self-contained HTML/Canvas viewer generated from the existing graph. A community plugin adds installation/runtime scope; a hosted app adds deployment/maintenance. Neither is necessary. Three-dimensional positions and perspective are rendered with Canvas, without adding a dependency or service. The generated visual concept defines a near-black navy canvas, warm/cool constellation colours, a flat left filter rail, central search, right symbol inspector and restrained bottom camera controls. All counts and labels come from real data rather than the concept's illustrative numbers.

Keep the entire graph searchable. Group stars by source area; preserve Graphify community IDs as details. Display only real edges, with an explicit overview sampling count and complete focused-neighbour counts. Search, constellation filters, click/keyboard selection, connection navigation, camera reset, zoom, rotation and optional orbit work. Motion starts paused and respects reduced-motion. Empty/no-match states and a text-based result/connection list provide access without pointing at tiny stars. On mobile the rails collapse into accessible panels and retain 44px targets.

Generate the existing `graph.html` export after structural build/clustering. Compact data contains only labels, relative paths, source locations, groups, community IDs, kinds and indexed edges. Do not embed source contents, arbitrary metadata or credentials. Treat graph strings as untrusted: JSON script escaping, textContent-only DOM insertion, strict CSP, no network resources. Validate unique IDs, edge endpoints, paths, metadata SHA/counts and the sub-10MB publication boundary before replacing an HTML file.

Freeze the exporter and template with the existing reviewed automation program so later verified merges preserve the view. Do not change CI eligibility, publisher targets, checkpoints, credentials or log format. The running graph checkout and installed task remain untouched during development. Manual canonical-vault publication retains its existing exact-preview approval gate; stage concrete files first. Keep graphs, screenshots and environments untracked; preserve canonical note names and the November 13 review.

Acceptance: real 11,920-node snapshot renders and is searchable; node/edge counts and source SHA agree with input; malicious labels cannot become markup; offline rendering requests no resources; small-screen controls and keyboard paths work; focused Graphify tests and browser checks pass. Source implementation is reviewable separately from generated data and live publication.
