# Payments Task Focus and Obsidian note layer

Owner request: build Task Focus plus the Obsidian note layer, starting with payments, retaining Wolf default, Galaxy and automatic updates without recurring AI calls. This is the requested continuation of the existing viewer, implemented inline in its owned source lane/PR113.

Payments focus uses deterministic repository file paths (invoice/payment/wallet/refund/billing/Stripe/money/WF-card), not inferred semantics. All/Payments controls filter code and tests while allowing selected recorded relationships to extend beyond the focus. Layout switching retains the selected task focus; fresh publications still start Wolf/front/depth80 and All. Existing search, source filters, camera and last-good update behavior remain.

The note layer reads only the five existing canonical files:00 Project Brain.md,01 Current State.md,02 Decisions.md,04 Known Issues.md,05 Architecture Map.md. It creates at most five distinct blue diamond note stars with note titles, bounded payment-section headings, modification metadata and explicit backticked repository paths. No paragraph text, Raw, Implementation Log, Security notes or other vault folders are indexed. Historical headings remain references, never current-code/QA claims. Links to code are labelled "mentions file" and point only to exact paths in the verified graph; absent links prove nothing. Open in Obsidian uses the core open URI with the exact allowlisted absolute path; no plugin or write URI.

Only the loopback host reads notes. Metadata is merged into HTML in memory and refreshes through the existing30-second version mechanism; no vault metadata is added to canonical exports, graph.json, Git or another memory store. The exporter provides Payments offline and a notes-unavailable state. Missing/unsafe/oversize notes leave the code graph usable. Per-file stat/read consistency and cached metadata bound repeated work; notes cannot select arbitrary filesystem paths. Canonical notes are limited to2MB each, at most24matching sections and30explicit file references per note; truncation is visible. Plain paths only; reject redirected files/ancestors. No new HTTP route, cloud call, model extraction or recurring AI job.

One new standard-library runtime module,project-context.py, owns scope rules and the notes index. Exporter/host/template use it through the existing frozen program; manager/runner manifests expand from seven to eight files. The host re-renders the installed template from a verified compact payload so program upgrades work with older Universe exports too. Graph publication provenance/CI/Vercel gates are unchanged and separate from live note metadata.

Approaches: a local read-only metadata overlay (selected; smallest authorised scope), embedding vault content into every published export (unnecessary duplication), or semantic/model indexing (unnecessary usage/dependency). No full-note excerpts or Obsidian configuration changes. Browser QA verifies URI targets without launching an external application. Canonical Decisions/Security proposals go to the PR's memory steward under D-319; no IDs allocated by this lane.
